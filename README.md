# Linux & Git Practice

A collection of seven repositories consolidated into a single monorepo as part of my Linux, Git, and GitHub training.

This repository documents hands-on exercises involving version control, branching, repository management, collaboration workflows, and command-line tools.

## Topics Covered

- Git fundamentals and repository initialization
- Commits, branches, and merge workflows
- Working with remote repositories
- Forks and collaborative GitHub workflows
- `.gitignore` configuration
- Command-line practice
- Repository consolidation using `git subtree`

## Repository Structure

Each exercise is stored in its own directory. The original projects were maintained as separate GitHub repositories before being consolidated into this monorepo.

Some exercises contain only a small number of files because their primary purpose was to practice Git operations rather than develop a complete application.

## Git History

The repositories were consolidated using `git subtree` without squashing commits, preserving the history of the imported branches.

Additional branches from the original repositories are handled separately to preserve relevant training history.
